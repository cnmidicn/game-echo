# 回响原野 · Voxel Resonance

浏览器中的 3D 体素音乐塔防原型。Three.js 0.170.0（MIT），依赖已包含在 dist/vendor 中。音效由 Web Audio 合成，无需外部素材。

## 本地运行

在 dist 目录启动静态服务器：`python -m http.server 18943`，再访问 http://localhost:18943 。请通过 HTTP 打开，不要直接双击 HTML。

## 玩法

开始谱写后，16 拍扫描线持续演奏预置防线。选择四种乐器之一，在地面基座或底部音序器点击建造；右键回收返还 75% 费用。每波补给 45 碎片，过关补给 65，击败怪物获得 8。守住五波即获胜。

1–4 选择乐器；空格试听/暂停（战斗中持续播放）；V 切换俯瞰与第一人称。俯瞰可拖拽旋转与滚轮缩放；第一人称 WASD 移动，鼠标环视，Esc 释放鼠标；不支持锁定鼠标的浏览器可拖拽环视。

本版使用固定的 64 个乐器基座；自由体素编辑、存档、多人模式不在此原型范围。

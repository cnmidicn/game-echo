# 回响原野 · 林间守夜

面向桌面浏览器的第一人称体素音乐守护游戏。第二版围绕“点亮音石”这一种交互重做，不需要选择乐器、调整 BPM 或手动开始波次。

## 运行

在 dist 目录运行 `python -m http.server 19448`，打开 http://localhost:19448 。需要 WebGL 2 与 Web Audio；请通过 HTTP 打开。Three.js 0.170.0（MIT）随项目提供，无外部服务依赖。

## 操作和旅程

WASD 行走，按住鼠标拖动环视；双击可锁定鼠标，Esc 释放。靠近林间之心按 E 唤醒，再走近空石台按 E 或点击点亮。每块音石消耗一缕回响，位置决定音高与节拍。旋律自动演奏、自动攻击。

点亮三块音石会引来第一夜。完成三夜守护后迎来晨光。击败两只暗影补充一缕回响，每夜结束补充两缕。右上角可静音或暂停。

## 画面

程序生成的像素材质、批量体素地形和森林、溪水着色器、柔和泛光、雾、日夜渐变、空间合成音效、脚步与手持回响。光晕通过场景内柔光生成，避免多层全屏后处理拖慢第一人称操作。

该版本不含自由地形编辑、多人和存档。

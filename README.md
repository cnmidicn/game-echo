# 回响原野 · 林间守夜

3D 体素音乐守护小游戏。核心操作只有点击：空位建造、音塔升级。保留俯瞰与第一人称切换。

## 本地运行

在 dist 目录运行 `python -m http.server 21156`，打开 http://localhost:21156 。需要 WebGL 2 / Web Audio。Three.js 0.170.0（MIT）随项目提供，无服务端依赖。

## 一局怎么玩

点击“开始演奏”，再点亮三个金色位置。初始三缕回响刚好建造三座音塔；准备阶段没有倒计时，不会催促新玩家。第三座建好后显示 5 秒来袭倒计时，之后自动开始。

只用一种音塔。点击空位消耗 1 回响建造；再点已有音塔直接升级，无需确认面板。I 级伤害 25 / 射程 13；II 级花 2 回响，伤害 40 / 射程 14；III 级花 3 回响，伤害 60 / 射程 15。金色升级箭头表示当前资源足够。最高 III 级，资源不足不会扣费。

音塔自动演奏攻击。三波分别 5、8、10 只敌人，总计 23 只，最后一只为巨影。波次间歇 8 秒，也可主动点击“现在就开打”。敌人出生点靠近前排，让玩家更快听见第一声攻击。

## 连奏和奖励

6 秒内连续击退敌人会自动连奏；3 / 6 / 10 连奏分别获得 1 / 1 / 2 额外回响，得分倍率依次升到 1.25 / 1.5 / 2，上限 2。击败两只敌人另获 1 回响。每波连奏独立，核心受击会中断当前连奏。

每波结束补充 2 回响；零漏怪额外补充 1 回响；核心恢复 1 生命，上限 6。奖励以短暂庆祝提示出现，无需选择。回响容量 9。

## 操作

V / 右上角按钮切换视角。俯瞰点击建造或升级、拖动环视、滚轮缩放。第一人称 WASD 行走、拖动环视、靠近石台按 E 建造或升级；双击可锁定鼠标，Esc 释放。暂停会冻结敌人、倒计时和连奏剩余时间。

## 结算和重玩

守住三波胜利。核心为 0 时失败。三星要求全程零漏怪且核心满血，回血不会抹去漏怪记录。结算显示得分、击退数、核心完整度、最高连奏与用时，本机最高分按当前版本保存在 localStorage。再次开局自动换一种合奏调性，无额外菜单。

## 验证

运行 `node --test tests/rules.test.mjs`，覆盖升级扣费、最高等级、波次阵容、连奏时间窗、里程碑奖励、回血上限与星级判定。浏览器验证三次点击开局、自动来袭、直接升级、连奏奖励、三波防守和巨影结算。

源码与像素材质均在 dist；历次截图在 artifacts，部署包在 outputs。固定建造位，不含自由地形编辑、多人和存档。
